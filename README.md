# CHAUHAN INFO SOLUTIONS — Frontend Exam Portal

## Upload to GitHub Pages
1. Extract this ZIP.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to your repository root.
3. Commit the files.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
6. Open the Pages URL after deployment completes.

## Important
- The current question bank is a demo sample repeated to demonstrate the interface. It is NOT an official UP teacher recruitment question bank.
- Includes candidate details, English/Hindi selection, timer, palette, green answered / grey unattempted / purple review states, submit confirmation, result summary, per-question timing, and CSV download.
- Email delivery to `PSARTS007@GMAIL.COM` is not enabled yet. Connect a backend later. Never put Gmail passwords or App Passwords in frontend files.
- This frontend does not provide server-side storage, secure candidate authentication, or anti-cheating controls.
